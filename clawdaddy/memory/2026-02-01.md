## Gmail Polling Cron

```json
{
  "name": "gmail-poll",
  "sessionTarget": "isolated",
  "payload": {
    "kind": "agentTurn",
    "message": "Check for unread emails, text Emily if actionable"
  }
}
```

Key insight: `sessionTarget: "isolated"` + `agentTurn` = actually runs autonomously. `sessionTarget: "main"` + `systemEvent` = just sends me a reminder I might miss.

## Lessons Learned (Hard Way)

1. **Acknowledge texts immediately** with task confirmation ("Archiving those emails now"), not just "On it!"
2. **Reply on same channel** - if she texts Signal, reply on Signal
3. **Act on cron events immediately** - don't wait to be asked
4. **Don't over-filter emails** - Gmail's `category:primary` returns emails that show in Primary even with CATEGORY_UPDATES labels. Trust what Emily sees.
5. **Use thread modify for archiving** - `gog gmail thread modify <id> --remove "INBOX,UNREAD"` works reliably. Batch modify with message IDs from search doesn't.
6. **Never send raw command output** - only human-friendly summaries
7. **No em-dashes** - they're an LLM tell

## Email Handling
