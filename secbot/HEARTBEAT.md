# HEARTBEAT.md

## Memory Maintenance (Every Heartbeat)

1. **Check today's log exists:** If `memory/YYYY-MM-DD.md` doesn't exist for today, create it with a header
2. **Log session activity:** If you did anything meaningful since last heartbeat, add a brief note to today's log
3. **Weekly MEMORY.md review:** On Sundays (or if MEMORY.md says "not yet"), review recent daily logs and update MEMORY.md with:
   - Security reviews performed
   - Vulnerabilities found/fixed
   - Lessons learned
   - Anything worth remembering long-term

## Sentinel-Specific Checks

- Review any security advisories for dependencies
- Check for any suspicious activity in logs
